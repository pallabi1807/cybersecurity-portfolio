# Pallabi Poria — Cybersecurity Fresher Portfolio

A responsive React + TypeScript + Vite portfolio using an editorial layout with a navy, steel-blue, and ice-blue palette.

## Install

Copy `src/App.tsx`, `src/App.css`, and `src/index.css` into the matching files in your Vite project.

From the project directory:

```bash
npm install
npm install lucide-react
npm run dev
```

## Before publishing

1. Update `profile` in `src/App.tsx` with your actual email, LinkedIn, and GitHub URLs.
2. Put your PDF résumé at `public/resume/Pallabi_Poria_Resume.pdf`.
3. Add actual GitHub repository and demo URLs in the `projects` array. Blank values intentionally display placeholders.
4. Verify the exact names and status of each certification and add certificate URLs when available.
5. Verify all project descriptions match the work you have actually completed.
6. Do not publish sensitive details, credentials, private IP addresses, logs, or findings from systems you are not authorized to test.

## Files

- `src/App.tsx` — sections, flagship AEGIS-SOC-GRC project section, mobile menu, email-copy action
- `src/App.css` — complete responsive design
- `src/index.css` — global reset and defaults

The Google Fonts import requires an internet connection. Fallback fonts are provided.
